Проверяемые сценарии включают изоляцию памяти, сохранение старых оригиналов, подробный свежий контекст, источник утверждений в запросе суммаризации, применение обновлённого резюме, отказ при невалидном резюме, очистку памяти/вложений/озвучки, запрет восстановления устаревшего резюме после reset, безопасное разделение Unicode Markdown, отсутствие подмены модели, передачу картинок файлом, текстовый fallback при TTS-ошибке, скрытый ввод 2FA, запрет исходящего RPC звонка и цепочку входящего звонка на имитации транспорта.

Также проверены управление обычными фразами («Отвечай голосом», «Пиши текстом», «Забудь нашу переписку»), остановка/возобновление без команд, отсутствие технических инструкций в ошибках и немедленный вопрос после переключения голоса без блокировки лимитом.

После доработки Markdown добавлены проверки таблиц, галочек, вложенных цитат, подписей изображений-ссылок, пересечений кода с выделениями, 250 отдельных выделений в длинном ответе, граничных UTF-16 позиций, скрытых спойлеров в тексте/голосе/fallback и настоящих классов ошибок Telethon. Визуальная проверка оформления внутри авторизованного Telegram-аккаунта всё ещё ожидает входа.

Непроверенное: Telegram login и реальные ответы/альбомы/voice notes в аккаунте; установление реального P2P-звонка, получение и передача живого звука, задержка и качество разговора. Для этого нужны Telegram API ID/hash, локальный вход и разрешённый собеседник. Идентичность модели за прокси подтверждается только контрактом/ID ответа провайдера; внутреннюю маршрутизацию A6 приложение проверить не может.

Личный архив работает отдельно от памяти ИИ и предназначен для всех личных диалогов. Реальный импорт Telegram, сохранение крупных файлов из аккаунта и работа на Railway не проверялись: пользователь отложил Telegram-вход. Приватный GitHub-репозиторий по указанному адресу недоступен предоставленному токену (HTTP 404); код пока не загружен.

## Подробная память собеседника, 7 октября 2026

- 206 автотестов и Ruff пройдены. Новые проверки охватывают версии фактов, источники, противоречия, даты рождения и возраст, изоляцию пользователей, редактирование во время извлечения, запоздавшие результаты, перезапуск очереди и запрет восстановления забытого из старых ответов.
- Проверены неподтверждённые сведения из голосовых, подтверждение только своего факта, отзыв при удалении подтверждения и исключение пересланного аудио. Реальное распознавание речи в этом прогоне не повторялось.
- На живом API дважды проверена синтетическая беседа: имя Анна Иванова, возраст 22, Алматы, короткий стиль; имя Олег из задания написать рассказ не попало в профиль; после исправления город сменился на Астану, сохранились проект Орион, бюджет и срок. Итоговый ответ после настройки тона: «Тебя зовут Анна, живёшь в Астане». Тесты не отправляли сообщений людям и не подключали локальную Telegram-сессию.
- В браузере проверены вход, отдельная карточка «Память ИИ», раскрытие исходной цитаты, возврат к диалогу и счётчик запросов карточек в расходах. HTTP-тесты проверяют обязательную авторизацию; tool-тест запрещает модели выбирать чужой user_id.
- Карточки строятся из новых принятых сообщений; старый архив не импортируется автоматически. Извлечение модельное, поиск лексический. Выборочное забывание консервативно исключает всю прежнюю рабочую историю из будущего контекста, сохраняя независимые структурированные факты и отдельный архив владельца. Это ограничение описано в README и сообщении пользователю.

## Голосовые инструменты агента, 7 октября 2026

- 215 автотестов пройдены. Проверены включение режима с содержательным ответом, сохранение настройки отдельно для каждого собеседника, разовая озвучка, отключение, чистая текстовая копия, отсутствие повторной отправки и двойного автоматического синтеза, отмена после изменения переписки, сбой Fish и последующего модельного ответа.
- Живой Claude на составную просьбу включить голос и рассказать стих вызвал `set_reply_mode`, затем `send_voice`. Fish Audio вернул MP3, локальный FFmpeg создал OGG/Opus. Доставка проверена имитацией Telegram-клиента с проверкой контейнера; тестовые голосовые людям не отправлялись.
- Второй живой запрос передал `[chuckle]` и `[long pause]` в Fish, получил голосовой файл и сохранил текст без тегов. Это проверка обработки скрипта и получения аудио, не инструментальная оценка естественности смеха и длительности пауз.
- Составная просьба «без голосовых, объясни почему небо голубое» выключила режим и дала объяснение без аудио. Фраза «Переведи на английский: “Отвечай голосом”» не вызвала инструментов и не изменила настройку.

- Подготовлены 34 настоящих клипа Fish со скоростью 0.7 и включены в пакет. Синтетическая двухсторонняя запись преобразована FFmpeg в OGG; проверены веб-просмотр, скачивание и HTTP 200 audio/ogg. Речь пользователя для теста не записывалась.

- Исторические записи выше описывают прежнее состояние: Telegram уже авторизован, GitHub и Railway доступны. Реальный входящий звонок и качество двусторонней связи в этом обновлении пока не проверены.

Добавлен маркер совместимости и отдельная проверка создания настоящего native SDK с защищённым клиентом без входа и сети; запрет исходящего RequestCall сохранён.
